        <h2 class="section-title">Frequently Asked Questions</h2>
        <p class="section-subtitle">Everything you need to know about markdown.new.</p>
        <div class="faq-list">
        <details>
          <summary>What is markdown.new?</summary>
          <div class="faq-answer">It converts any public URL into clean, structured Markdown optimized for LLMs and AI agents. It strips away HTML bloat (ads, scripts, styling) while preserving headings, lists, links, and tables &mdash; making web content AI-ready with up to 80% fewer tokens.</div>
        </details>
        <details>
          <summary>How do I use it?</summary>
          <div class="faq-answer">Three ways, no signup needed. <strong>Browser:</strong> prepend <code>https://markdown.new/</code> to any URL. <strong>cURL/API:</strong> POST a JSON body with <code>{"url": "https://example.com"}</code>. <strong>Options:</strong> add <code>method</code> (auto, ai, browser) and <code>retain_images</code> (true/false) as query params or in the POST body.</div>
        </details>
        <details>
          <summary>Is it free?</summary>
          <div class="faq-answer">Yes, always. No subscriptions, no paywalls. It&rsquo;s an open utility for developers, AI builders, and teams. Just respect the fair usage limits so the service stays reliable for everyone.</div>
        </details>
        <details>
          <summary>What are the rate limits?</summary>
          <div class="faq-answer">500 requests per day per IP address. If you exceed the limit, you&rsquo;ll receive an HTTP 429 response. Check the <code>x-rate-limit-remaining</code> header to track your usage. For heavier workloads, consider self-hosting the open-source logic.</div>
        </details>
        <details>
          <summary>How does the conversion pipeline work?</summary>
          <div class="faq-answer">It uses a three-tier fallback chain. <strong>Tier 1:</strong> requests the URL with <code>Accept: text/markdown</code> for native Markdown. <strong>Tier 2:</strong> passes HTML through Cloudflare Workers AI <code>toMarkdown()</code>. <strong>Tier 3:</strong> renders JS-heavy pages in a headless browser via Cloudflare Browser Rendering. The fastest successful tier wins.</div>
        </details>
        <details>
          <summary>Are there any limitations?</summary>
          <div class="faq-answer">Public URLs only &mdash; paywalled or authenticated pages won&rsquo;t work. JS-heavy sites using the browser method add ~1&ndash;2s of latency. Images are excluded by default (enable with <code>retain_images=true</code>). Very large pages may be truncated.</div>
        </details>
        <details>
          <summary>Is it legal to convert web pages?</summary>
          <div class="faq-answer">Yes, for public pages. markdown.new uses standard HTTP requests (like your browser) and doesn&rsquo;t store or republish content. Always respect each site&rsquo;s Terms of Service and <code>robots.txt</code>. Avoid mass-scraping copyrighted content for redistribution.</div>
        </details>
        <details>
          <summary>Can I crawl an entire website?</summary>
          <div class="faq-answer">Yes! Use <a href="/crawl">/crawl</a> to crawl up to 500 pages from any site. It uses Cloudflare&rsquo;s Browser Rendering <code>/crawl</code> API with async job tracking. You can configure page limits (up to 500), crawl depth (up to 10), and enable JS rendering. Results are stored for 14 days.</div>
        </details>
        <details>
          <summary>How can I block this service from my site?</summary>
          <div class="faq-answer">Our bot identifies as <code>markdown.new/1.0</code>. Add this to your <code>robots.txt</code>: <code>User-agent: markdown.new Disallow: /</code>. You can also block by User-Agent at the WAF/server level, use a <code>llms.txt</code> file to signal AI usage preferences, or return <code>X-Robots-Tag: noindex</code> headers.</div>
        </details>

          copyBtn.addEventListener('click', async function() { await navigator.clipboard.writeText(data.content); copyBtn.textContent = 'Copied!'; setTimeout(function(){ copyBtn.textContent = 'Copy'; }, 2000); });
          actions.appendChild(copyBtn);

          var dlBtn = document.createElement('button'); dlBtn.className = 'btn btn-secondary'; dlBtn.textContent = 'Download';
          dlBtn.addEventListener('click', function() {
            var blob = new Blob([data.content], { type: 'text/markdown' });
            var u = URL.createObjectURL(blob); var a = document.createElement('a'); a.href = u; a.download = data.filename; a.click(); URL.revokeObjectURL(u);
          });
          actions.appendChild(dlBtn); header.appendChild(actions); el.appendChild(header);

          var rawDiv = document.createElement('div'); rawDiv.className = 'raw-content';
          var pre = document.createElement('pre'); pre.textContent = data.content;
          rawDiv.appendChild(pre); el.appendChild(rawDiv);
          el.classList.add('visible');
        }

      });
